# PGC 历史记录菜单操作设计

## 意图

对 PGC 历史记录，在 TV 卡片菜单中只隐藏“UP 主页”操作。保留“详情”，并让它打开与点击 PGC 卡片相同的页面（季详情页）。

## 范围与约束

- `HistoryScreen` 目前依赖默认的 `FavoriteResourceType.Video`。
- 传入 `Pgc` 会同时隐藏“详情”和“稍后再看”，并改变其余操作使用的类型，因此保持现有资源类型不变。
- 为“UP 主页”单独增加可见性开关；仅在选中历史项的业务类型为 `"pgc"` 时禁用它（调用点一次比较，不加辅助函数）。
- “详情”对 PGC 卡片保持可用，并与点击卡片一样导航：PGC 打开季详情，UGC 打开视频详情。
- 其余菜单条目保持现有行为。
- 不要改变其他调用点的菜单行为或资源类型。

## 方案

- **选定：为“UP 主页”增加可见性开关，并让“详情”走卡片点击回调。** 只隐藏指定的条目，并让 PGC 的“详情”打开季页面。
- 复用 PGC 资源类型。否决原因：它还会隐藏“详情”和“稍后再看”，并改变其他操作的处理方式。
- 保留现有“详情”行为（用原始 id 打开 `VideoInfoActivity`）。否决原因：PGC 卡片会打开错误的页面。

## 验收

打开 PGC 历史卡片菜单时不出现“UP 主页”，但保留“详情”；选择“详情”会打开与点击卡片相同的页面。非 PGC 的历史菜单保持不变。
