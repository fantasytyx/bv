# BV

哔哩哔哩第三方客户端，面向 Android Mobile 与 Android TV。核心领域为视频内容消费：浏览、播放、弹幕、用户互动。

## 内容类型

**UGC（用户生成内容）**：
UP 主自主上传的视频，按分区组织。
_Avoid_: 用户视频、投稿

**PGC（专业生成内容）**：
平台引进或制作的版权内容，涵盖番剧、国创、电影、纪录片、电视剧、综艺。按季度/剧集组织，可能需付费或大会员。
_Avoid_: 番剧、影视

**直播**：
实时流媒体内容。分推荐、关注、分区三种浏览方式，通过弹幕流互动。

**互动视频**：
由交互节点和选择项构成的非线性视频。用户在分支点做出选择，决定后续剧情走向。
_Avoid_: 分支视频

## 内容结构

**分区（UGC）**：
UGC 的顶级分类，共 31 个（动画、游戏、鬼畜、音乐、舞蹈、影视、娱乐、知识、科技、资讯、美食、短剧、汽车、时尚、运动、动物圈、Vlog、绘画、AI、家居、户外、健身、手工、旅行、乡村、亲子、健康、情感、生活记录、生活经验、星海）。每个视频属于一个分区。
_Avoid_: 频道、分类

**剧集（Episode）**：
PGC 季度内的单个播放单元，按 EP 编号排序。每集有独立的播放进度。
_Avoid_: 集、话

**季度（Season）**：
PGC 内容的完整播放季，包含若干剧集。每个季度有独立的封面、简介、追剧状态。
_Avoid_: 季、季番

**分P（UGC）**：
单个 UGC 视频内的多段落，按 P1/P2 编号。每个分P 有独立的弹幕池和播放进度。
_Avoid_: 分段

**合集（UGC Season）**：
UP 主将已发布视频按主题组织的播放列表，可包含多个 Section。每个 Section 含若干视频。
_Avoid_: 系列、播放列表

**收藏夹（Favorite Folder）**：
用户自行创建的视频收藏文件夹，可容纳视频、音频、合集。一个视频可加入多个收藏夹。
_Avoid_: 收藏列表

**稍后再看列表**：
用户标记"稍后再看"的临时视频清单，作为快速回访入口。
_Avoid_: 待看列表

## 播放

**播放模式（Play Mode）**：
当前视频结束后的行为：单视频播完即停、单视频循环、合集/分P 顺序、合集/分P 逆序、UGC 列表顺序/逆序、推荐视频随机、自定义策略。
_Avoid_: 连播模式

**下一个播放动作**：
视频结束后的决策：不播放、播推荐视频、播剧集/分P 的下一个、播下一个或推荐。与播放模式互斥——播放模式决定播放列表的遍历方式，下一个播放动作决定要不要自动播下一个。

**画质（Quality）**：
视频分辨率等级：240P、360P、480P、720P、720P60、1080P、1080P+、1080P60、4K、HDR、杜比视界、8K。部分画质需登录或大会员。
_Avoid_: 清晰度、分辨率

**视频编码（Codec）**：
视频流的压缩标准：AVC(H.264)、HEVC/HVC1(H.265)、DVH1(杜比视界)、AV1。
_Avoid_: 编码格式

**音频编码**：
音轨的质量等级：64K、132K、192K、Hi-Res、杜比全景声。
_Avoid_: 音质

**直播源流**：
直播使用的流媒体协议：HLS 自动选择、HLS 强制 AVC、FLV 固定 AVC。
_Avoid_: 直播线路

**画面旋转**：
播放时对画面施加 0°/90°/-90°/180° 的角度旋转，用于适配竖屏视频或特殊拍摄角度。
_Avoid_: 旋转模式

**画面比例**：
在播放器窗口内缩放画面的策略：默认、4:3、16:9、9:16、等宽、等高、拉伸。
_Avoid_: 缩放模式

**竖屏视频修复**：
针对竖屏视频在某些设备上渲染异常的补偿方案：不处理、限制分辨率不高于 1080P、强制使用 TextureView 渲染。
_Avoid_: 竖屏修复

**片头/片尾跳过**：
PGC 内容提供 OP/ED 时间戳，播放器可选择自动跳过片头片尾片段。
_Avoid_: OP/ED 跳过

**快进/快退**：
播放时按可配置的秒数向前/向后跳跃。
_Avoid_: 快进快退、跳转

**播放进度记忆**：
记录视频的播放位置，支持从历史位置恢复播放或从头开始。
_Avoid_: 历史位置、续播

**音量均衡（Audio Balance）**：
按服务端下发的响度元数据对音频施加静态整体增益，把不同视频的响度对齐。增益为纯标量，不改变音调与音色。挡位：关闭、标准模式、影音模式。
_Avoid_: 响度均衡、音量归一化

**响度元数据（Volume Info）**：
播放地址随流下发的响度信息：分段测得的响度 `measured_i` / 真峰值 `measured_peak`，以及标准模式目标 `normal_target_i`、影音模式目标 `high_dynamic_target_i`。没有该字段的源（如 gRPC 的 PGC 播放地址）音量均衡整体旁路。
_Avoid_: 音量信息、loudness

**跳过静音（Skip Silence）**：
自动略过音轨中的静音段。只在 2.5 倍速及以上生效，用于减少高倍速下的语音失真；对连续说话或无静音的视频无效。
_Avoid_: 静音跳过、无声快进

**CDN 候选地址**：
播放地址接口针对同一清晰度返回的多条流地址，按线路/域名区分。

**CDN 速度实测**：
播放时对各候选地址做小样本下载测速，结果累积成评分（`CdnSpeedStore`），用于排序并在必要时自动切换到更快的地址。
_Avoid_: 测速、选路

## 弹幕

**弹幕**：
视频播放时叠加在画面上的实时评论文字，从右向左滚动或固定在顶部/底部。
_Avoid_: 弹幕评论

**滚动弹幕**：
从右向左穿越屏幕的弹幕，速度 = 基础速度 × 播放速率 × 用户速度偏好。同轨道需等前一条完全进入后才可生成新弹幕。
_Avoid_: 普通弹幕 (mode=1)

**顶部/底部弹幕**：
水平居中固定在屏幕顶部或底部，持续约 4 秒后消失。
_Avoid_: 固定弹幕 (mode=5/4)

**弹幕轨道**：
屏幕上弹幕分行的逻辑轨道，轨道高度由字号和密度决定。所有轨道满时新弹幕进入等待队列。
_Avoid_: 行、lane

**弹幕密度**：
控制轨道行高的参数：稀疏（行高高）、标准、密集（行高低）。密度越高同屏弹幕条数越多。
_Avoid_: 密度级别

**弹幕字重**：
弹幕文字的粗细：标准、粗体。
_Avoid_: 字体粗细

**弹幕字号缩放**：
按百分比缩放弹幕文字，范围 25%~200%。
_Avoid_: 字号比例

**弹幕透明度**：
弹幕整体的不透明度，可 9 级调节。
_Avoid_: 不透明度

**弹幕显示区域**：
弹幕在屏幕上占据的垂直比例（0~1），超出区域的弹幕不渲染。
_Avoid_: 区域比例

**弹幕速度偏好**：
用户手动设定的滚动速度系数（1~10 档），独立于视频播放速率。
_Avoid_: 速度级别

**弹幕描边**：
弹幕文字的像素级描边宽度，使文字在浅色背景下可辨识。
_Avoid_: 描边粗细

**弹幕过滤等级**：
按用户等级（直播）或内容分级（点播）过滤弹幕，屏蔽低等级或不适当内容。
_Avoid_: 过滤级别

**弹幕遮罩**：
通过画面分析让弹幕避开人脸/字幕区域的智能渲染技术。
_Avoid_: 防遮挡

**弹幕分片**：
点播弹幕按 6 分钟窗口分段加载，播放器按当前进度预加载附近的分片。
_Avoid_: 段、segment

**弹幕时钟**：
驱动弹幕动画的时间基准。采用限速跟随策略平滑播放器的时间抖动，避免弹幕卡顿与漂移。
_Avoid_: 弹幕时间轴

## 用户操作

**点赞（Like）**：
用户对视频点赞/取消点赞。
_Avoid_: 喜欢

**投币（Coin）**：
用户对视频投出 B 币（一次性，不可撤销），表示对创作者的认可。
_Avoid_: 打赏

**收藏（Favorite）**：
用户将视频加入/移出指定收藏夹。支持多文件夹。
_Avoid_: 加收藏、收藏夹

**稍后再看（ToView）**：
用户将视频标记为稍后再看，加入稍后再看列表。
_Avoid_: 待看

**关注（Follow）**：
用户关注/取关 UP 主。支持悄悄关注和黑名单。
_Avoid_: 订阅

**关注关系**：
用户与 UP 主之间的关系类型：无关系、悄悄关注、关注、互相关注、黑名单。
_Avoid_: 关注状态

**视频操作状态（Video Action State）**：
单个视频上用户已完成的操作快照（点赞/投币/收藏）。在 TV 端多个 UI 表面间共享，惰性加载并防竞态覆盖。

## 追番/追剧

**追番/追剧**：
用户关注 PGC 季度以获取更新通知。状态分为：想看、在看、看完。
_Avoid_: 订阅番剧

## 动态

**动态**：
UP 主发布内容的时间线流。包含视频投稿、转发、图文、直播推荐、PGC 更新、专栏文章。
_Avoid_: 动态流、timeline

## 界面

**界面模式**：
应用的 UI 适配方式：自动检测（根据屏幕尺寸选择 TV/Mobile）、强制使用 TV 界面、强制使用 Mobile 界面。
_Avoid_: UI 模式、显示模式

**导航切换模式**：
TV 端在导航项之间移动的交互方式：聚焦时自动切换、聚焦后确认才切换。
_Avoid_: 导航模式

**主题**：
应用的色彩方案：跟随系统（自动）、深色、浅色。
_Avoid_: 皮肤、暗黑模式

**控制栏按钮**：
播放器底部操作按钮的组合，包括：播放速度、画质、编码、直播线路、音频、画面旋转、画面比例、弹幕、字幕、播放模式、播放列表、推荐视频、UP 主空间、评论、视频详情、视频简介、设置、刷新。按钮支持排序和显隐。
_Avoid_: 控制按钮、操作按钮

**屏幕刷新率匹配**：
让屏幕刷新率跟随视频帧率的选项。开启后视频画面更平滑，但滚动弹幕会变卡；默认关闭。
_Avoid_: 帧率匹配、可变刷新率

**导航项排序**：
主屏左侧主导航项（首页、UGC、PGC、直播导航组）可自定义组内各项的顺序与显隐。
_Avoid_: 菜单排序

**卡片操作菜单**：
在列表的视频卡片上长按确认键（或按菜单键）打开的菜单，含 UP 主页、详情、点赞、收藏、投币、稍后再看、删除等入口。
_Avoid_: 右键菜单、上下文菜单

## 字幕

**CC 字幕**：
人工制作的字幕，有语言标识和制作者信息。
_Avoid_: 人工字幕

**AI 字幕**：
机器自动生成的字幕。分普通 AI 字幕和 AI 翻译字幕。
_Avoid_: 自动字幕

**AI 字幕状态**：
字幕的公开程度：未公开（仅后台可见）、露出（用户可见）、辅助（作为 CC 字幕的补充）。
_Avoid_: AI 状态

## 风控与账号

**风控**：
B 站对未登录或异常请求的限制机制。触发后接口返回 `v_voucher`（`code=0` 或 `-352`），需完成极验验证后重放原请求。
_Avoid_: 拦截、封控

**极验验证（Geetest）**：
风控的验证手段，产品形态可能是点击（`product: 'bind'`）或滑块。滑块必须发送 DOWN → MOVE → UP 才能通过，只发一次点击永远过不了。
_Avoid_: 验证码、captcha

**gaia_vtoken**：
极验验证通过后换取的凭证，随原请求重放以解除风控限制。前置的 `v_voucher` 是一次性凭证。
_Avoid_: 风控 token

**Web Cookie 自动维护**：
客户端定期刷新并回写 web 侧 cookie（如 `buvid3` / `buvid4`），保证 web 接口指纹自洽——同一整型指纹必须来自同一次 `finger/spi` 签发。
_Avoid_: cookie 同步

## 代理

**代理区域**：
用于解锁区域限制 PGC 内容的代理出口位置：中国大陆、香港、台湾。
_Avoid_: 区域
